# Listrak Job Scraper

Creating a job scraper in Python using Listrak job API to notify job opportunities.

## How to run
* This won't work without you inside the python env.
1. `source path-to-project-directory/venv/Scripts/activate`
    - You'll know if it works if you see the (venv) with each new command.
2. `python url.py`
3. Exit env with `deactivate` command
